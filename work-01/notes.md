1) Открыл веб-страницу <https://console.yandex.cloud>.
2) Перешёл на "Compute Сloud" -> "Виртуальные Машины".
3) Открыл форму "Создать виртуальную машину".
4) Переименовал ВМ на gubaydullin-09-web-manual.
5) Кликнул "Добавить метку" и добавил пару {ключ: значение} -- {created-by: console}.
6) В поле "Образ загрузочного диска" в графе "Marketplace" нажал на "Ubuntu" и выбрал версию "24.04".
7) В поле "Диски и файловые хранилища" выбрал тип HDD и ввёл размер "25 ГБ".
8) В поле "Вычислительные ресурсы" в "графе Своя конфигурация" были предустановлены "Платформа"="Intel Ice Lake" и "vCPU"=2.
9) В поле "Вычислительные ресурсы" в "графе Своя конфигурация" выбрал Гарантированную долю vCPU - 20%, RAM автоматически установился на 2 ГБ, после чего поставил галочку на "Прерываемая" для строки "Дополнительно".
10) В поле "Сетевые найстройки" выбрал зону доступности "ru-cenral1-d" (подсеть "default/default-ru-central1-d"), а "Публичный IP-адрес" по умолчанию был выставилен на "Автоматически".
11) В поле "Доступ" с выбранным типом доступа "SSH-ключ" в строке "Логин" ввёл "student", развернул dropdown "SSH-ключ" и кликнул "Добавить ключ".
12) В окне "Добавление SSH-ключа" назначил имя `gubaydullin-09-wsl`. В терминале WSL прописал

```bash
cat ~/.ssh/id_ed25519.pub
```

скопировал выведенную строку в текстовое поле "SSH-ключ" окна "Добавление SSH-ключа" и нажал "Добавить".
13) Переключил значение строки "Резервное копирование" на False.
14) Нажал "Создать ВМ", после чего ожидал изменения статуса Виртуальной Машины на "Running".
15) Скопировал IP-адресс ВМ (при первом запуске это было 158.160.243.30) и прописал в терминал WSL

```bash
ssh student@158.160.243.30
```

подтвердил цифровой отечаток, написав yes и открыл окружение виртуальной машины в своём WSL.
16) Обновил пакеты ВМ, установил nginx и посмотрел статус работы этой службы:

```bash
sudo apt update
sudo apt instal -y nginx
systemctl status nginx
```

17) Убедившись в том, что служба nginx запущена, проверил работу веб-сервера в браузере по адресу http://158.160.243.30. Затем персонализировал страницу, отображаемую по адресу, добавив hostname и добавив на страницу слово "cloudlab":

```bash
set +H
sudo sed -i "s|Welcome to nginx!|cloudlab on $(hostname)|g" \
  /var/www/html/index.nginx-debian.html
```

После чего снова проверил вручную веб-страницу по данному адрессу.
