## Каталоги работ

| Каталог | Работа |
| --- | --- |
| `work-01/` | Практика № 1: работа с Yandex Cloud через веб-консоль и CLI |
| `work-02/` | Практика № 2: cloud-init, две ВМ и сетевой балансировщик |

Файлы CI/CD практики № 3 размещаются в корне репозитория.

## Запуск стенда

Команды выполняются в WSL/Ubuntu. Нужны Bash, Yandex Cloud CLI (`yc`),
`jq`, `envsubst`, `curl`, `ssh` и SSH-ключ `~/.ssh/id_ed25519.pub`.
Профиль `yc` должен быть настроен на свой каталог Yandex Cloud.

```bash
cd ~/folder/iac-gubaydullin
```

| Стенд | Создать | Удалить |
| --- | --- | --- |
| Практика № 2 | `bash work-02/create.sh` | `bash work-02/destroy.sh` |
| ДЗ № 1 | `bash hw-01/create.sh --web-count 2` | `bash hw-01/destroy.sh` |

После завершения cloud-init проверить стенд ДЗ № 1:

```bash
bash hw-01/check.sh
```

Код возврата: `0` — все проверки прошли, `1` — есть ошибка.
Параметры варианта: префикс `gubaydullin-09`, порт `8027`, слово `cloudlab`.
Практика № 2 и ДЗ № 1 используют общий префикс: перед запуском другого
стенда нужно удалить предыдущий. Подробности ДЗ № 1 — в [hw-01/README.md](hw-01/README.md).
